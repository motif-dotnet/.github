# Motif.NET

**Opinionated, AI-assisted tooling for building .NET apps, from first sketch to production.**

Motif.NET is a suite of tools that cover the whole development lifecycle. Each tool does one stage well, and the output of one is the input to the next, so a design you sketch can become a plan a coding agent builds from.

## Tools

| Tool | What it does | Status |
|---|---|---|
| [**Motif Sketch**](https://github.com/motif-dotnet/Motif.Sketch) | Sketch a system context diagram and a ports-and-adapters design, then export SVG pictures and a Markdown solution plan a coding agent can build stubs from. Runs in the browser, with no server and no accounts. [Try it](https://motif-dotnet.github.io/Motif.Sketch/). | Built |

More tools will follow.
